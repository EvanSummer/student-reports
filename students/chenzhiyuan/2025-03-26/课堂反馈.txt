课堂所学习内容：

核⼼思想 1：掌握程序中的条件判断逻辑，理解关系运算与逻辑运算如何组合形成复杂的判断条件。

核⼼思想 2：运⽤ if-else 分⽀结构，实现程序流程的多路径控制，以应对不同的输⼊或状态。

核⼼思想 3：理解逻辑“短路原则”对程序执⾏效率和逻辑正确性的影响，并能在代码中加以利⽤。

核⼼知识点 1：关系运算符 - 包括等于（ == ）、不等于（ != ）、⼤于（ > ）、⼩于（ < ）、⼤于等
于（ >= ）和⼩于等于（ <= ），⽤于⽐较两个值的关系，结果为真（1）或假（0）。

核⼼知识点 2：逻辑运算符 - 包括逻辑⾮（ ! ）、逻辑与（ && ）、逻辑或（ || ），⽤于组合多个条
件。

核⼼知识点 3：逻辑短路原则 - 在逻辑与（ && ）运算中，若左侧为假则右侧不计算；在逻辑或
（ || ）运算中，若左侧为真则右侧不计算。此原则影响程序效率和执⾏路径。

核⼼知识点 4：条件分⽀结构 - if 、 if-else 、 if-else if-else 结构的语法与适⽤场景。强调代
码块必须⽤⼤括号 {} 括起，以及 else if 和 else 后不接⼩括号的规范。

核⼼知识点 5：问题拆解与应⽤ - 结合数学运算（如整除 / 、取模 % ）提取数字特定位数，并利⽤条
件判断进⾏分析（如判断⼗位是否为5）。讲解构成三⻆形的⼏何条件（两边之和⼤于第三边）及其
在程序中的逻辑表达。

     核⼼概念讲解：系统讲解了关系运算符、逻辑运算符的真值表、短路原则，以及 if-else 分
     ⽀的完整语法结构。

     随堂练习与互动：通过“判断数字⼗位是否为5”等题⽬，练习了数位提取与条件判断的结合。

     辑错误等进⾏了现场纠正和讲解。
